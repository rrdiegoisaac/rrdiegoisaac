## Sobre mí

Ingeniero Comercial con **3 años como Data Analyst & Data Engineer** en telecomunicaciones, trabajando para clientes como **Movistar, VTR y OnNet**. Me hago cargo del ciclo completo del dato: extracción, transformación, modelado y visualización.

- Desarrollo y administro **SQL Server** en producción: stored procedures, jobs, triggers, índices y data marts.
- Construyo **pipelines ETL en Python** con web scraping (Selenium), APIs REST y SQLAlchemy.
- Diseño **modelos estrella en Power BI**, optimizo DAX y automatizo reportes con la API REST de Fabric.
- Diseño los fondos de mis reportes en **Figma** y los cargo como SVG para que sean más livianos.
- Compito en **Kaggle** con modelos predictivos y publico datasets abiertos.
